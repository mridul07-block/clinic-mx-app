## Keeping them true

- **What they hold:** every button and label in bold is quoted from the app. They hold no clinical content (rules, criteria, consent wording, questionnaire items or prices); the app holds that.
- **When the app changes:** when a ticket changes a screen a guide names, update that guide in the same change.
- **Not live yet:** each guide's "Not live yet" list shrinks as WhatsApp, AI, Part B consent, the video library, questionnaires and patient content go live. Refresh them at go live.
- **The clinic's review:** the wording waits for the clinic's review (DECISION OPS-04). The live sessions wait for the clinic's dates, staff and venues.
